# sdr-slc-rtld 1.0

First public release.

Reference RTL-SDR implementation of the SDR-SLC protocol suite: mDNS
discovery, the SDR-SLC JSON control plane over TCP, and VITA-49 IQ over UDP,
conformant to SDR-SLC-CP-1.0 Release 1.3 and SDR-SLC-VITA-1.0 Release 1.2.
The daemon shell (control plane, logging, mDNS, config, systemd unit) is
shared with sdr-slc-bladerfd 1.0.
